# FISCUS AI Financial Workflow State Fixtures

This open, fully synthetic reference dataset contains 25 hand-authored scenarios for testing finance-critical workflow transitions without confusing an AI suggestion, a human approval, an external-provider response, and a committed accounting effect.

The fixtures support review of:

- deterministic transition guards and human approvals;
- provider uncertainty, retries, idempotency, and reversals;
- bank reconciliation, invoices, e-documents, expenses, collections, exchange rates, ledger workflows, and organization authorization;
- reconstructible audit events and user-visible status aligned with source-of-truth state.

## Project context

The state model reflects the controlled-automation principles used by [FISCUS AI](https://fiscusai.org/), an AI-supported financial operating system for Turkish SMEs. Product availability and live integrations remain conditional on plan, organization authority, business eligibility, provider readiness, and user approval.
